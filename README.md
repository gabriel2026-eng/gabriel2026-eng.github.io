# Gabriel · portfolio

Automations, websites and AI email assistants for small businesses. This repository is the source of my portfolio site, published with GitHub Pages.

## What's inside

| Folder | What it is |
| --- | --- |
| `index.html` | The portfolio page |
| `site-demo/` | Demo: one-page website for a fictional woodworking shop (HTML, CSS, JavaScript, no frameworks); English, with a Romanian version in `site-demo/ro/` |
| `code/sheets-automation.js` | Demo: Google Apps Script that turns form orders into clean sheet rows, confirmation emails, owner alerts and statuses (`orders-sample.csv` shows the filled sheet) |
| `code/email-assistant.py` | Demo: Python assistant that categorises customer emails and drafts replies with the Claude API (`email-assistant-report.md` is a sample report from demo mode) |
| `assets/` | Screenshots |

All three projects are demos built on fictional businesses and made-up data. No client data is included, and the scripts contain no keys or real addresses.
